# herdr-relay intro: three storylines

Recommendation: **A**, because a stranger follows it in one look: the same Herdr on three screens, then a finger
changes one of them and the Mac stays as it was. Every screen in it is a real render from the bridge.

Assumptions: 16 to 20 s, 16:9, silent (the README shows it as an autoplaying muted GIF; the mp4 is the same cut),
no paid items.

## A. One frame that rebuilds (built)

- **Device and form:** the feature as the hook; one frame that keeps rearranging itself and never cuts away.
- **What the viewer sees and feels:** Herdr's window on a Mac, the bridge starting beside it with each mod in its own
  host, then the same layout arriving on an iPad and a phone. A finger drags the iPad's sidebar wider and the Mac's
  window, uncovered again, is unchanged. Calm, factual, nothing invented.
- **First two seconds:** the Mac window on the studio-gray ground, "Your Herdr runs on your Mac" landing word by word.
- **Beats:** Mac → bridge (`herdr-relay start`, mods spawned) → iPad and phone arrive → drag on the iPad → Mac
  unchanged → end card.
- **Look:** the README preview's light studio sweep, the product's own dark UI, Geist titles, one blue accent.
- **Sound:** none; the film is made to play muted inline.

## B. Away from the desk (not built)

- **Device and form:** a moment in someone's day; object-to-object chain.
- **What the viewer sees and feels:** Claude Code working in Herdr on the Mac, the camera follows the Mac's terminal
  line into a pocket, the phone's lock screen receives "Finished: Claude Code — Add a dark mode toggle", the tap opens
  that pane on the phone. Relief: you did not have to watch it.
- **First two seconds:** the Claude Code pane with "Working…" and the clock in the menu bar moving on.
- **Beats:** working → walk away → push arrives → tap → the pane on the phone → end card.
- **Look:** the same product UI, the kit's iPhone lock screen, a warmer evening ground.
- **Sound:** a soft bed, the system notification's own sound as the one hit.

## C. The layout comes apart (the bold one, not built)

- **Device and form:** the object is the explanation; match cuts.
- **What the viewer sees and feels:** the Mac window's parts (sidebar, tabs, panes) lift off as separate layers,
  pass through a hairline "sandbox" gate where each mod's host lights up, and re-dock into the phone's pager and the
  iPad's split. It shows how the bridge recomposes rather than that it does.
- **First two seconds:** the Mac window tilting into an exploded stack of its layout's nodes.
- **Beats:** explode → gate → re-dock on iPad → re-dock on phone → reassemble → end card.
- **Look:** a white technical ground, blueprint hairlines, the product UI on the layers.
- **Sound:** dry clicks as each layer docks.
